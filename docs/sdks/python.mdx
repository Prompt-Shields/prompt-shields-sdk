# Python SDK

The Prompt Shields Python SDK is a drop-in replacement for the OpenAI and Anthropic clients. Every LLM call is wrapped with structured telemetry — fail-open, so a collector outage never blocks a model call.

<Info>
  For a deep-dive walkthrough with debugging tips and production patterns,
  see the standalone [SDK Developer Guide](https://github.com/Prompt-Shields/prompt-shields-sdk/blob/main/SDK_GUIDE.md).
</Info>

## Installation

```bash
# OpenAI only
pip install "prompt-shields[openai]"

# Anthropic only
pip install "prompt-shields[anthropic]"

# Both providers
pip install "prompt-shields[all]"
```

Requires Python 3.11+.

## Per-Request Metadata

For data that varies per call, use `ps_metadata`:

```python
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Review this candidate file..."}],
    ps_metadata={
        "data_sources": ["candidates_db", "linkedin_api"],
        "output_destination": "hiring_dashboard",
        "risk_tags": ["pii", "gdpr"],
        "session_id": "review-2025-04-12-001",
        "user_id": "hr_user_42",
    },
)
```

| Field | Purpose |
|-------|---------|
| `data_sources` | Systems feeding data into the prompt — populates data flow lineage |
| `output_destination` | Where AI output goes — completes the lineage graph |
| `risk_tags` | Free-form tags for governance filtering (`gdpr`, `hipaa`, ...) |
| `session_id` | Groups related calls in a multi-turn conversation |
| `user_id` | Opaque identifier (hash before passing if you need to anonymize) |

## Auto-Instrumentation

To get telemetry without changing call sites, call `instrument()` once at
startup. It patches whichever of these SDKs are installed, sync and async:

| Vendor | Calls | Streaming |
| --- | --- | --- |
| `openai` | `chat.completions.create`, `responses.create` | yes |
| `azure_openai` | the same, on `AzureOpenAI` / `AsyncAzureOpenAI` clients | yes |
| `anthropic` | `messages.create` | yes |
| `google` | google-genai `models.generate_content` | not yet |
| `mistral` | mistralai `chat.complete`, `chat.complete_async` | not yet |
| `cohere` | `Client.chat` (v1), `ClientV2.chat` (v2), and async clients | not yet |
| `bedrock` | boto3 `bedrock-runtime` `converse`, `invoke_model` | not yet |

Azure calls are tagged `azure_openai` and recorded under the deployment name.
To price them, pass `azure_deployments={"prod-chat": "gpt-4o"}`; an unmapped
deployment is priced by the model Azure reports. Bedrock `invoke_model` usage
is read from the response headers, so the response body stream is never read.
Streaming methods of the newer vendors (`generate_content_stream`,
`chat.stream`, `chat_stream`, `converse_stream`, ...) are not instrumented yet.

```python
import openai
import prompt_shields

prompt_shields.instrument(ps_api_key="ps-...", use_case="support-bot")

client = openai.OpenAI()  # unchanged app code
client.chat.completions.create(model="gpt-4o", messages=[...])  # emits an event
```

Unset arguments fall back to `PS_API_KEY`, `PS_COLLECTOR_URL`,
`PS_BUSINESS_UNIT`, `PS_USE_CASE`, `PS_OWNER`, `PS_DATA_CLASSIFICATION`,
`PS_ENVIRONMENT`, `PS_CALLING_SERVICE`, `PS_ATLAS_URL` and `PS_ATLAS_API_KEY`.
Pass `vendors=("openai",)` to instrument only some providers. `"openai"` also
covers Azure clients (tagged `azure_openai`); pass `("azure_openai",)` alone to
instrument Azure without plain OpenAI.

- Calling `instrument()` again does nothing; `uninstrument()` restores the original methods.
- Missing packages are skipped. Telemetry errors never affect the call.
- Calls made through `ShieldsClient` are not counted twice. To skip other calls, wrap them in `with prompt_shields.suppress_instrumentation():`.
- `.with_raw_response` calls, and positional-argument calls, are not instrumented.

## Cost-Aware Routing

Attach a `RouteHint` to a call to express *intent*. The SDK emits `X-PS-*`
headers; the **gateway** picks the cheapest model that satisfies the hint
(transparent-by-default, with a per-route override). Calling a provider
directly instead of the gateway simply ignores the headers, so hints are
always safe to add.

```python
from prompt_shields import RouteHint, ShieldsOpenAI

client = ShieldsOpenAI(api_key="sk-...", ps_api_key="ps-...", base_url=PS_GATEWAY_URL)

# Cheap-and-capped for a throwaway prompt; gateway downgrades the model.
client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Classify sentiment: ..."}],
    route=RouteHint(quality="draft", max_cost=0.005),
)

# Force the strong tier, skipping the router entirely.
client.chat.completions.create(
    model="auto", messages=[...], route=RouteHint(model_group="frontier"),
)
```

| Field | Type | Header | Meaning |
|-------|------|--------|---------|
| `quality` | `"draft" \| "balanced" \| "critical"` | `X-PS-Quality` | Intent, not a model name. |
| `max_cost` | float | `X-PS-Max-Cost` | Per-call USD ceiling. |
| `model_group` | str | `X-PS-Route` | Explicit override — bypasses the router. |
| `allow_cache` | bool (default `True`) | `X-PS-Cache: off` when `False` | Opt out of the gateway's semantic cache. |

Precedence: `model_group` > `quality`/`max_cost` > gateway default. An empty
`RouteHint()` emits no headers (identical to today's behavior). Every event
records `requested_model` (e.g. `"auto"`) vs `served_model` (what actually
ran) so savings are provable. Works on the async clients too.

## Configuration Reference

| Argument | Type | Default | Notes |
|----------|------|---------|-------|
| `api_key` | str | — | LLM provider key. Never sent — only a SHA-256 fingerprint. |
| `ps_api_key` | str | — | Prompt Shields tenant key. |
| `vendor` | str | `"openai"` | Or `"anthropic"`. Set by typed subclasses. |
| `ps_collector_url` | str | `http://localhost:8000` | Set to your production collector URL. |
| `business_unit` | str | — | Becomes part of the asset merge key. |
| `use_case` | str | — | Maps to `use_case_name` in the registry. |
| `owner` | str | — | Maps to `owner_email`. |
| `data_classification` | str | — | `public` / `internal` / `confidential` / `restricted`. |
| `environment` | str | — | Separate envs are separate assets. |
| `calling_service` | str | — | Service/app name for dedup fallback. |
| `scan_pii` | bool | `True` | Disable to skip local PII detection. |
| `send_prompt_text` | bool | `False` | Opt-in to log full prompt content. |
| `pricing_table` | dict | built-in | Override token-to-USD pricing. |

## Privacy Model

| Field | Sent by default? |
|-------|------------------|
| Vendor + model | Yes |
| Token counts, latency, cost | Yes |
| Tool call names | Yes |
| PII category labels | Yes |
| API key fingerprint | Yes (SHA-256, truncated) |
| Business metadata | Yes (only what you pass) |
| **Prompt content** | **No** (unless `send_prompt_text=True`) |
| **Response content** | **Never** |
| **Raw API key** | **Never** |
| **Tool call arguments** | **Never** |

## PII Detection

The SDK runs a local pattern-based scanner before sending telemetry:

```python
from prompt_shields import detect_pii_categories

detect_pii_categories("Email jane@acme.com about SSN 123-45-6789")
# → ['email', 'ssn']
```

Detected categories: `email`, `phone`, `ssn`, `credit_card`, `ip_address`, `iban`, `health_data`, `financial_data`.

## Cost Estimation

Built-in pricing table for OpenAI, Anthropic, and Google models:

```python
from prompt_shields import estimate_cost

estimate_cost("openai", "gpt-4o", tokens_in=1000, tokens_out=2000)
# → 0.0225 (USD)
```

Override with a custom table:

```python
client = ShieldsOpenAI(
    api_key="sk-...",
    ps_api_key="ps-...",
    pricing_table={
        ("openai", "gpt-4o"): (0.0020, 0.0080),  # negotiated rate
        ("custom", "internal-llm-v1"): (0.0001, 0.0002),
    },
)
```

## Fail-Open Guarantees

1. **LLM calls never blocked by telemetry** — response returned before telemetry sent
2. **No prompt content leaves the host** unless explicitly opted in
3. **Telemetry errors never raise** — logged at WARN, buffered for retry
4. **Buffer overflow drops oldest events** — never blocks the app
